# Идея: мобильное приложение AuksionGO (Android / iOS)

_Цепочка `idea-review`, 16.11.2026. Решает владелец._

## Бриф

**1. Идея (словами владельца).** «Мне нужна аппка, какой стэк возьмём». Предварительно агент предложил Expo (React Native) + TypeScript; владелец попросил прогнать идею через цепочку.

**2. Зачем.** Быть в App Store и Google Play, присылать push-уведомления (победа, срок оплаты 10%, повторные торги, начало торгов), быстрый вход и привычный для части покупателей канал. Сайт уже удобен на телефоне и десктопе.

**3. Что есть сейчас** (в `main`):
- Сайт покупателя `apps/miniapp` (React + Vite, исторически назван miniapp): каталог, лот, вход по телефону и SMS-коду, допуск, комната торгов (SSE `/lots/:id/events`), выкуп (10% за 15 мин → код и 24 ч), повторные торги, уведомления на сайте (таблица `Notification`, `/me/notifications`). Админка `apps/admin`.
- API `apps/api` (NestJS + Fastify + Prisma + PostgreSQL + Redis): сессия покупателя на сайте — httpOnly-cookie + CSRF (`modules/auth/buyer-session.service.ts`); переходный вход Telegram с Bearer JWT; метка устройства в cookie (антифрод); ограничение частоты запросов; SMS через `SmsProvider` (`SMS_MODE` fake/disabled — провайдер не выбран); платежи через `PaymentProvider` (fake — партнёр не выбран: Uzum / Click / Payme).
- Общий пакет `packages/shared` (правила торгов, деньги, расписание).
- План мобайла от 13.11: `docs/plans/mobile-app.md` (частично устарел: Telegram Mini App, WebSocket, 30%); скилл `mobile` (`.claude/skills/mobile/SKILL.md`).
- Аккаунтов Apple Developer / Google Play нет; МЧЖ в процессе регистрации (юрист готовит оферту — документ «AuksionGO: описание продукта для оферты»).

**4. Ограничения.** Без over-engineering, один сервер. Правила торгов — только на сервере. Деньги — целые сумы. Команда — владелец и партнёр, каждый со своим AI-агентом (Claude Code, Codex). Решения из `docs/PROJECT_CONTEXT.md` §8 действуют.

**5. Вопросы к ревьюерам.**
- Стек: Expo (React Native) против обёртки сайта (Capacitor) и PWA — что лучше для пилота?
- Что входит в первую версию приложения, а что позже?
- Вход и сессия в приложении (cookie не подходит), push, лента торгов, оплата внутри приложения и правила сторов.
- Сроки и порядок работ; что можно делать до появления аккаунтов сторов, SMS и платёжного партнёра.
