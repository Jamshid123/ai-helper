Нативные MainButton/BackButton, тема Telegram, палитра B, ru/uz.

- Выкладка: `infra/docker-compose.prod.yml` (свой Postgres 16 без внешнего порта, Mini App на `127.0.0.1:3401`, read-only контейнер без capabilities), `infra/server/bootstrap.sh` + workflow `server-bootstrap.yml` (пользователь deploy по ключу, `.env` с паролем БД, сгенерированным на сервере, nginx vhost + Let's Encrypt с проверкой `nginx -t` и откатом), workflow `deploy.yml` (push в `main` → CI → образ → сервер → health check → откат → кнопка меню @auksionchi1_bot).
- Скилл `ux-review`: ревью UI/UX уровня senior product designer — сценарии AuksionGO, скриншоты (iPhone/SE, light/dark, ru/uz), чек-лист (скорость, доверие и деньги, состояния, WCAG 2.2, платформа, визуал), шкала серьёзности, формат отчёта.
- `docs/plans/mobile-app.md`: план мобильного приложения — предпосылки, стек, 8 этапов, риски сторов (оплата допуска, политика аукционов, удаление аккаунта).
- `docs/plans/backend-mvp.md` — утверждённый план backend и боевого режима (5 этапов), исключение для ночных пушей в рабочую ветку в `CLAUDE.md`.
- `docs/reviews/ux-2026-11-13.md` — первое UX-ревью демо-стенда: 16 находок (5 высоких), что работает, компромиссы, что не проверено.
- `apps/api`: каркас backend — NestJS 11 + Fastify + Prisma 6, конфиг из env на zod (без фолбэков секретов, `PAYMENTS_MODE=disabled` по умолчанию, fake запрещён в production, CORS без `*`), `/api/v1/health` (PostgreSQL + Redis), pino-логи с redact, защитные заголовки; тесты на настоящих PostgreSQL/Redis (пересоздание схемы только в базе `*_test`).
- `infra/Dockerfile.api`; в `infra/docker-compose.prod.yml` — сервисы `redis` и `api` (`127.0.0.1:3400`, read-only, без capabilities).
- Deploy: сборка и передача образа API, `prisma migrate deploy` перед запуском, health-check Mini App + API, очистка старых образов обоих сервисов.
- CI: PostgreSQL и Redis как service-контейнеры, сборка `packages/shared`, проверочная сборка образа API.
- API: схема БД домена — пользователи, ограничения, лоты, допуски, предложения цены, заказы, обязательства выкупа, outbox, журнал аудита, настройки; деньги `BigInt`, время `timestamptz`; уникальности (номер предложения в лоте, ключ идемпотентности, допуск, место в очереди выкупа, `providerTxId`) и CHECK-ограничения в миграции; тесты гарантий схемы.
- API: ядро торгов `BidsService.placeBid` — транзакция с блокировкой лота, идемпотентность (повтор ключа и гонка одинаковых ключей), проверки допуска/окна/статуса/ограничения/лидерства, минимальная цена по правилам ТЗ, монотонный порядковый номер, событие `bid.accepted` в outbox; инжектируемые часы (`Clock`/`FakeClock`); 10 тестов сценариев приёмки.
- API: вход из Mini App — проверка подписи Telegram `initData` (HMAC-SHA256, срок ≤ 1 ч, сравнение за постоянное время), `POST /api/v1/auth/telegram` (создание/обновление покупателя, публичное имя по ТЗ), сессия JWT HS256 на 1 час, глобальный guard «закрыто по умолчанию» + `@Public()`, `GET /api/v1/auth/me` без телефона и telegramId в ответе; новые обязательные переменные `TELEGRAM_BOT_TOKEN`, `JWT_SECRET` (генерируется на сервере при выкладке).
- API: каталог `GET /api/v1/lots`, `/lots/:id`, `/schedule` (публично; формат совпадает с контрактом Mini App, деньги строками, полный IMEI не отдаётся); `POST /api/v1/lots/:id/bids` — предложение цены по HTTP с валидацией и понятными отказами (`NO_ADMISSION`, `BID_TOO_LOW` + минимальная цена и др.).

### Changed
- `packages/shared` собирается в CommonJS (`dist-cjs`, esbuild) для API; Vite-приложения по-прежнему берут исходники.
- `deepmerge-ts` закреплён на `^8` через `pnpm.overrides` (GHSA-ggr8-5vv4-36mx в зависимости Prisma CLI).
- Mini App по итогам UX-ревью: таймер в комнате не обрезается на маленьких экранах; правила возврата взноса и пункт выдачи видны до оплаты допуска (ТЗ); сумма выше минимальной — второе касание «Подтвердить»; карточка «Как это работает» на главной (скрываемая); даты ru/uz своим форматтером («20-noyabr, 09:00»); контраст вторичного текста и плашек ≥ 4.5:1; «Оплатить 12 000 сум» и серое неактивное состояние кнопок; кнопка «Участвовать» внутри карточки лота; в демо полоса «Идут демо-торги»; закреплённая кнопка на карточке лота вне Telegram; цели касания ≥ 44 pt; подпись «в комнате»; подсветка нового предложения.
- Mini App UX: в каталоге у идущих лотов кнопка «Участвовать» / «В комнату торгов»; после допуска — сразу в комнату; в комнате крупная текущая цена с лидером и таймером, панель действия внизу экрана, варианты цены показывают итоговую сумму, при лидерстве кнопка скрыта (вместо бледной неактивной), без допуска — кнопка «Получить допуск».
- Тексты: «ставка / поставить» → «предложить цену», «ход торгов», «ваша цена — лучшая» (ru/uz).
- CI: группа concurrency учитывает вызывающий workflow (вызов из Deploy не отменяется параллельным CI).
